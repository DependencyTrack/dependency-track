title: v4.14.4
type: patch

**Features:**

* Add support for ingestion of CycloneDX 1.7 BOMs - [apiserver/#6966]
* Use modern CycloneDX tools metadata in BOM exports - [apiserver/#7259]
* Remove unnecessary enrichment when querying for individual projects - [apiserver/#7258]
* Stop bumping `AffectedVersionAttribution.lastSeen` on every mirroring run - [apiserver/#7257]
* Reduce churn of vulnerable software associations during mirroring - [apiserver/#7256]

**Fixes:**

* Fix HTTP 500 when deleting vulnerabilities that are referenced by analyses - [apiserver/#7260]
* Fix `User-Agent` header missing for various HTTP requests - [apiserver/#7254]
* Fix Jira notification tests reporting success when no issue was created - [apiserver/#6792]

For a complete list of changes, refer to the respective GitHub milestones:

* [API server milestone 4.14.4](https://github.com/DependencyTrack/dependency-track/milestone/70?closed=1)
* [Frontend milestone 4.14.4](https://github.com/DependencyTrack/frontend/milestone/55?closed=1)

We thank all organizations and individuals who contributed to this release, from logging issues to taking part in discussions on GitHub & Slack to testing of fixes.

Special thanks to everyone who contributed code to implement enhancements and fix defects:
