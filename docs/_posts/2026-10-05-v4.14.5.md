**Fixes:**

* Fix OS package scanning for Trivy analyzer - [apiserver/#7593]
* Fix Trivy findings dropped for PURLs with URL-valued qualifiers - [apiserver/#7592]
* Fix NuGet package names being treated as case-sensitive for vulnerability matching - [apiserver/#7565]
* Fix PyPI package names not being PEP 503-normalized for vulnerability matching - [apiserver/#7564]
* Fix various issues with NPM version comparisons - [apiserver/#7563]
* Fix `NEW_VULNERABLE_DEPENDENCY` notifications not including project tags - [apiserver/#7500]
* Fix NPEs during DataNucleus L1 cache eviction - [apiserver/#7499]
* Fix scheduled portfolio vulnerability analysis aborting during cache eviction - [apiserver/#7448]
* Fix `ReferenceError` when trying to remove a policy condition - [frontend/#1887]
* Fix project properties modal showing stale data after navigating to another project - [frontend/#1888]
* Fix incorrect dependency graph link in component search - [frontend/#1889]

For a complete list of changes, refer to the respective GitHub milestones:

* [API server milestone 4.14.5](https://github.com/DependencyTrack/dependency-track/milestone/76?closed=1)
* [Frontend milestone 4.14.5](https://github.com/DependencyTrack/frontend/milestone/59?closed=1)

We thank all organizations and individuals who contributed to this release, from logging issues to taking part in discussions on GitHub & Slack to testing of fixes.
