**Fixes:**

* Fix BOM validation failing when XML contains CDATA - [apiserver/#7751]
* Fix suppression not being recorded in audit trail when creating a new violation analysis - [apiserver/#6011]
* Remove eMudhra root CA from container image trust store - [apiserver/#7762]

For a complete list of changes, refer to the respective GitHub milestones:

* [API server milestone 4.14.6](https://github.com/DependencyTrack/dependency-track/milestone/79?closed=1)
* [Frontend milestone 4.14.6](https://github.com/DependencyTrack/frontend/milestone/62?closed=1)

We thank all organizations and individuals who contributed to this release, from logging issues to taking part in discussions on GitHub & Slack to testing of fixes.
