**Features:**

* Extend distro-aware version matching with Red Hat support - [apiserver/#8032]

**Fixes:**

* Mitigate CVE-2026-114938 by disabling Hotspot base64 intrinsics in container images - [apiserver/#8039]
* Fix false positives caused by Red Hat package versions being compared in the wrong format - [apiserver/#8032]
* Fix false positives caused by RHEL components matching Red Hat Hummingbird advisories - [apiserver/#8032]
* Fix allowable values of `sortOrder` parameter in OpenAPI spec - [apiserver/#8030]
* Bump dependencies and base images to resolve various CVEs - [apiserver/#7900], [frontend/#2066], [frontend/#2123]

For a complete list of changes, refer to the respective GitHub milestones:

* [API server milestone 4.14.7](https://github.com/DependencyTrack/dependency-track/milestone/83?closed=1)
* [Frontend milestone 4.14.7](https://github.com/DependencyTrack/frontend/milestone/66?closed=1)

We thank all organizations and individuals who contributed to this release, from logging issues to taking part in discussions on GitHub & Slack to testing of fixes.
